# Assets Folder

This folder contains images used in the bento boxes section.

## Required Images

### 1. manhattan-map.png
- A map of Manhattan
- Recommended size: 600x600px or larger
- Will be displayed as a grayscale background in the location box
- You can use a screenshot from Google Maps or Apple Maps

**How to get it:**
1. Go to Google Maps or Apple Maps
2. Center on Manhattan, NY
3. Take a screenshot
4. Crop to a square
5. Save as `manhattan-map.png` in this folder

### 2. cwru-logo.png
- Case Western Reserve University logo
- Recommended: Official logo with transparent background
- Recommended size: 400x400px or larger (square)
- Will be displayed in a white rounded box

**How to get it:**
1. Download from: https://case.edu/umc/our-brand/visual-identity/university-logos
2. Use the primary logo (preferably PNG with transparent background)
3. Save as `cwru-logo.png` in this folder
